# Nexus

Gestão ágil de vendas, orçamentos, estoque e serviços.

## Repositório GitHub
Este projeto está vinculado ao repositório: [giufarlosdias-max/moneyvoice](https://github.com/giufarlosdias-max/moneyvoice)

## Deploy
O deploy oficial deste projeto está em: [moneyvoice.vercel.app](https://moneyvoice.vercel.app)

## Funcionalidades
- Gestão de Vendas e Orçamentos
- Controle de Estoque
- Ordens de Serviço (OS)
- AI Animação (Criação de vídeos com IA)
- Gestão de Clientes e Produtos
